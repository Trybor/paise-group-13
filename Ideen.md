## Browsergame wie Monkeytype

- Projektidee und Problemstellung definieren
- Zielgruppe und wichtigste Anwendungsfälle identifizieren
- AI zur Anforderungsanalyse einsetzen
- Mindestens 8–10 User Stories erstellen
- Funktionale und nichtfunktionale Anforderungen definieren
- Anforderungen priorisieren (Must/Should/Could)
- MVP-Scope festlegen
- Anforderungen auf Widersprüche und Unklarheiten prüfen


Problemstellung: Ich habe mir eine neue Tastatur angelegt und möchte tippen üben.
Zielgruppe: Käufer einer neuen Tastatur, Gamer.


Anforderungen:

Tipptest 
 	-> vorgegebene Wörter sollen nachgetippt werden
	-> innerhalb einer vorgegebenen Zeit
	-> kein Login, nur Namenseingabe
 	-> Schwierigkeit einstellen
	-> Zeit einstellen
	-> Countdown
	-> Sprache einstellen
	-> Livefeedback (Highlighting) welche Zeichen richtig/falsch getippt wurden
Ergebnis sehen
	-> wie viele zeichen habe ich richtig getippt
	-> zeichen pro Minute
	-> wörter pro Minute
	-> accuracy
	-> visuelle Darstellung der Statistiken
Multiplayer
	-> Lobby erstellen
	-> Leute einladen mit einem Link
	-> Leute kicken
	-> Zeit einstellen (optional)
	-> live gegeneinander die selben wörter abtippen
	-> Ergebnis von allen Lobbyteilnehmern im Vergleich anzeigen
	-> Leute kicken
	-> mehrere Runden spielen
	-> Gesamtstatistik anzeigen (für jede Runde und jeden Spieler)
