# KeyDuel – Tipptrainer mit Multiplayer

> Arbeitstitel · PAISE-Gruppe 13

## Idee

Ein Tipptrainer im Browser: vorgegebene Wörter in einer festen Zeit nachtippen und danach Tempo und Genauigkeit sehen. Zusätzlich können Freunde über einen Link einer Lobby beitreten und **live gegeneinander dieselben Wörter tippen**. Dafür braucht es keinen Account, nur einen Namen.

## Problem

Wer eine neue Tastatur kauft, tippt anfangs langsamer und macht mehr Fehler. Zum Eingewöhnen braucht man eine Übung, die sofort ohne Anmeldung startet, messbares Feedback gibt und motiviert. Bestehende Tipptrainer sind meist Einzelspieler-Tools oder verlangen für Multiplayer einen Account.

## Zielgruppe

- **Käufer:innen einer neuen Tastatur:** wollen schnell üben und ihren Fortschritt sehen.
- **Gamer / Freundesgruppen:** wollen sich spontan miteinander messen.

## Ziel

Eine im Semester umsetzbare Web-App, mit der man
1. alleine einen Tipptest machen und das Ergebnis sehen kann und
2. per Einladungslink mit anderen gleichzeitig tippen und die Ergebnisse vergleichen kann.
